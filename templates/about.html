Edge-IIoTset Dataset

Network traffic records from the Edge-IIoTset dataset are used for training and evaluating the intrusion detection models. Selected network and protocol characteristics are processed to support intelligent traffic analysis.

Random Forest Intelligence

Random Forest analyzes the selected network features and determines whether the traffic represents Normal or Attack behavior. When malicious activity is detected, the system further identifies the corresponding attack type.

Machine Learning
03

Confidence Analysis

Prediction probabilities generated by the trained model are converted into confidence percentages. The application presents the prediction confidence using Low, Medium, or High levels to provide clearer interpretation of each result.

04

SHAP Explainability

SHAP identifies the contribution of individual network features toward each model decision. This enables users to understand which characteristics influenced the Normal or Attack prediction produced by the model.
